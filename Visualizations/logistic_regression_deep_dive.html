§ 01

The Perceptron

The story of logistic regression begins in 1958 with Frank Rosenblatt's Perceptron — the first computational model of a biological neuron. It is the most primitive classifier imaginable, yet its DNA lives inside every modern neural network.

How the Perceptron Works

Given a feature vector x = [x₁, x₂, ..., xₙ] and a weight vector w = [w₁, w₂, ..., wₙ], the perceptron computes a weighted sum, adds a bias, then fires a hard decision:

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = wᵀx + b

ŷ = step(z) = { 1 if z ≥ 0
              { 0 if z < 0

where b is bias (or equivalently, a weight w₀ with input x₀ = 1)
Example 01
Is a student likely to pass an exam?

Suppose we have two features: hours studied (x₁) and hours slept (x₂).
Learned weights: w₁ = 0.9, w₂ = 0.4, bias b = −5

StudentHours Studied (x₁)Hours Slept (x₂)z = wᵀx + bPerceptron says
Alice780.9×7 + 0.4×8 − 5 = +4.5Pass (1)
Bob250.9×2 + 0.4×5 − 5 = −1.2Fail (0)
Carol560.9×5 + 0.4×6 − 5 = +2.9Pass (1)

The Perceptron Learning Rule

Weights are updated whenever the perceptron makes an error. For each training sample (xᵢ, yᵢ):

w ← w + α · (yᵢ − ŷᵢ) · xᵢ
b ← b + α · (yᵢ − ŷᵢ)

α = learning rate (small positive number, e.g. 0.01)
If correct: (yᵢ − ŷᵢ) = 0, so NO update happens
If wrong: (yᵢ − ŷᵢ) = ±1, so weights SHIFT toward correct answer
✓
Perceptron Convergence Theorem: If the data is linearly separable, the Perceptron is guaranteed to find a perfect separating hyperplane in a finite number of steps.
§ 02

The Problem with the Perceptron

The Perceptron works elegantly when data is perfectly separable. But real-world data rarely is. Three fundamental flaws emerge:

1

Hard Decisions — No Confidence

The step function outputs only 0 or 1. It can say "pass" but cannot say "70% likely to pass." There is no notion of probability or certainty. Two students with z = 0.01 and z = 9.5 both get "Pass" — yet clearly one is far more certain.

2

Non-Differentiable Loss

The step function has zero gradient everywhere except at 0 (where it's undefined). This makes it impossible to use calculus-based optimization. Modern ML requires smooth, differentiable objectives to apply gradient descent.

3

No Probabilistic Interpretation

The perceptron output ŷ ∈ {0,1} has no statistical meaning. We cannot compute calibrated probabilities or use likelihood-based training — tools that are essential in Bayesian reasoning and model evaluation.

❌ Perceptron

step(z)

Output: {0, 1}
Gradient: 0 everywhere
Probabilistic: No
Non-separable: Fails to converge

✓ We need

smooth(z)

Output: (0, 1) continuous
Gradient: always defined
Probabilistic: P(y=1|x)
Non-separable: Converges

⚡
The Big Question: Can we find a smooth, bounded, differentiable function that squashes any real number z ∈ (−∞, +∞) into the range (0, 1) — and give it a probabilistic meaning?
§ 03

Enter the Sigmoid

The solution is the sigmoid function (also called the logistic function) — and its derivation is beautifully motivated by the concept of odds.

Deriving Sigmoid from Odds

Suppose p = P(y=1|x) is the probability of a positive outcome. Define the odds ratio:

①
odds = p / (1 − p)
Ratio of success to failure probability. Range: (0, ∞)
②
log-odds = log( p / (1−p) ) = z = wᵀx + b
Take log (makes range: −∞ to +∞). Set equal to the linear score. This is the "logit" link.
③
log(p / (1−p)) = z
p / (1−p) = eᶻ
p = eᶻ(1−p)
p = eᶻ − p·eᶻ
p(1 + eᶻ) = eᶻ
Algebraically solving for p in terms of z
④
σ(z) = p = eᶻ / (1 + eᶻ) = 1 / (1 + e⁻ᶻ)
The Sigmoid function! Smooth, differentiable, output ∈ (0,1)

Key Properties of Sigmoid

σ(0) = 0.5 // at z=0, exactly 50% probability σ(z) → 1 as z → +∞ // asymptote at 1 σ(z) → 0 as z → −∞ // asymptote at 0
σ'(z) = σ(z) · (1 − σ(z)) // beautiful self-referential derivative!
Derivation — Sigmoid Derivative
Why σ'(z) = σ(z)(1 − σ(z))
σ(z) = (1 + e⁻ᶻ)⁻¹

dσ/dz = −1 · (1 + e⁻ᶻ)⁻² · (−e⁻ᶻ)
= e⁻ᶻ / (1 + e⁻ᶻ)²

Note: e⁻ᶻ/(1+e⁻ᶻ)² = [1/(1+e⁻ᶻ)] · [e⁻ᶻ/(1+e⁻ᶻ)]
= [1/(1+e⁻ᶻ)] · [1 − 1/(1+e⁻ᶻ)]
= σ(z) · (1 − σ(z)) ✓
💡
The self-referential derivative σ'(z) = σ(z)(1 − σ(z)) is extremely powerful — it means we never need to recompute the sigmoid during backpropagation. If we already know the output σ(z), the derivative is free.
§ 04

The Logistic Regression Model

We now have all pieces to define Logistic Regression. It assumes a Bernoulli distribution over the output, where the success probability is modeled by the sigmoid of a linear combination:

// Full model definition
z = wᵀx + b // linear score
p̂ = σ(z) = 1/(1+e⁻ᶻ) // predicted probability

P(y=1 | x; w,b) = σ(wᵀx + b)
P(y=0 | x; w,b) = 1 − σ(wᵀx + b)

// Unified in one line (Bernoulli PMF):
P(y | x; w,b) = p̂ʸ · (1−p̂)^(1−y)

Decision Boundary

We classify as class 1 when p̂ ≥ 0.5, which happens exactly when z ≥ 0, i.e., when wᵀx + b ≥ 0. This is a linear hyperplane — in 2D, a line; in 3D, a plane; in nD, a hyperplane.

Decision boundary: wᵀx + b = 0

For 2D (x₁, x₂): w₁x₁ + w₂x₂ + b = 0
Rearranging: x₂ = −(w₁/w₂)x₁ − (b/w₂)

// This is a straight line! Logistic Regression is a linear classifier.
Example — Back to Pass/Fail
Probability Outputs vs Hard Decisions

With w₁ = 0.9, w₂ = 0.4, b = −5:

Studentz = wᵀx+bσ(z) = probabilityDecision (threshold 0.5)
Alice (7h study, 8h sleep)+4.5σ(4.5) = 0.989 (98.9%)Pass
Bob (2h study, 5h sleep)−1.2σ(−1.2) = 0.231 (23.1%)Fail
Carol (5h, 6h)+2.9σ(2.9) = 0.948 (94.8%)Pass
Dan (4h, 5h)+0.1σ(0.1) = 0.525 (52.5%)Pass (barely!)

Notice: Dan is barely predicted to pass (52.5%), while Alice is almost certain (98.9%). This granularity was impossible with the Perceptron.

§ 05

Deriving the Loss Function

Now we must answer: how do we measure how wrong our model is? For the Perceptron, errors were counted discretely. For Logistic Regression, we derive the loss from first principles using Maximum Likelihood Estimation (MLE).

Step 1: The Likelihood

Given training data {(x⁽¹⁾,y⁽¹⁾), ..., (x⁽ᵐ⁾,y⁽ᵐ⁾)}, assume samples are i.i.d. The joint likelihood of all labels is:

L(w,b) = ∏ᵢ P(y⁽ⁱ⁾ | x⁽ⁱ⁾; w,b)
= ∏ᵢ p̂ᵢ^y⁽ⁱ⁾ · (1 − p̂ᵢ)^(1−y⁽ⁱ⁾)

// We want to MAXIMIZE this over w and b

Step 2: Log-Likelihood (for numerical stability)

Products of small probabilities underflow floating point. Take the log — maximizing log-likelihood is equivalent to maximizing likelihood:

log L(w,b) = ∑ᵢ [ y⁽ⁱ⁾ · log(p̂ᵢ) + (1−y⁽ⁱ⁾) · log(1−p̂ᵢ) ]

// log of product → sum of logs // If y=1: only log(p̂ᵢ) survives // If y=0: only log(1−p̂ᵢ) survives

Step 3: Convert to a Loss (Minimize)

By convention we minimize a loss (not maximize a likelihood). Negate and average:

J(w,b) = − (1/m) ∑ᵢ [ y⁽ⁱ⁾ · log(p̂ᵢ) + (1−y⁽ⁱ⁾) · log(1−p̂ᵢ) ]

Binary Cross-Entropy Loss (BCE)

Intuition Behind Cross-Entropy

→

When y = 1 (true label is positive)

Loss = −log(p̂). If p̂ → 1 (confident and correct), log(1) = 0, loss → 0. If p̂ → 0 (confident but wrong!), log(0) → −∞, loss → ∞. The model is heavily penalized for confident mistakes.

→

When y = 0 (true label is negative)

Loss = −log(1 − p̂). If p̂ → 0 (correct), loss → 0. If p̂ → 1 (wrong!), loss → ∞. Same penalty structure.

📉 Cross-Entropy Loss Curve
■ Loss when y=1: −log(p̂) ■ Loss when y=0: −log(1−p̂)

📌
Why not use MSE for classification? Mean Squared Error (ŷ − y)² combined with sigmoid creates a non-convex loss surface with many local minima. Cross-entropy with sigmoid yields a convex loss — gradient descent is guaranteed to find the global minimum!
§ 06

Gradient Descent & Weight Updates

With our loss function defined, we need to find weights w, b that minimize it. We do this using gradient descent: repeatedly nudge weights in the direction that reduces loss the most.

Deriving the Gradient

We need ∂J/∂w and ∂J/∂b. This requires the chain rule through three functions:

J(w,b) → p̂ = σ(z) → z = wᵀx + b

Chain rule: ∂J/∂w = (∂J/∂p̂) · (∂p̂/∂z) · (∂z/∂w)
Full Derivation
Computing ∂J/∂wⱼ step by step
For a single training point (to keep notation clean):
①
∂J/∂p̂ = −[y/p̂ − (1−y)/(1−p̂)]
Derivative of −[y·log(p̂) + (1−y)·log(1−p̂)]
②
∂p̂/∂z = σ(z)(1−σ(z)) = p̂(1−p̂)
Sigmoid derivative (derived earlier!)
③
∂z/∂wⱼ = xⱼ
z = w₁x₁ + ... + wⱼxⱼ + ..., linear in w
④
∂J/∂wⱼ = −[y/p̂ − (1−y)/(1−p̂)] · p̂(1−p̂) · xⱼ

= −[y(1−p̂) − (1−y)p̂] · xⱼ
= −[y − yp̂ − p̂ + yp̂] · xⱼ
= −(y − p̂) · xⱼ
= (p̂ − y) · xⱼ
Beautiful simplification! The p̂(1−p̂) cancels out perfectly.

The Update Rules

// Gradient for entire dataset (m samples):
∂J/∂wⱼ = (1/m) ∑ᵢ (p̂ᵢ − yᵢ) · xⱼ⁽ⁱ⁾
∂J/∂b = (1/m) ∑ᵢ (p̂ᵢ − yᵢ)

// Weight update (gradient descent step):
w ← w − α · ∂J/∂w
b ← b − α · ∂J/∂b

// In vectorized form (efficient NumPy-style):
w ← w − (α/m) · Xᵀ(σ(Xw+b) − y)
b ← b − (α/m) · sum(σ(Xw+b) − y)
✨
Remarkable: The gradient (p̂ᵢ − yᵢ)·xⱼ is identical in form to the Perceptron update rule (yᵢ − ŷᵢ)·xⱼ! The difference: Logistic uses soft error (p̂ − y) ∈ (−1,1), Perceptron uses hard error (y − ŷ) ∈ {−1,0,1}.

The Full Training Algorithm

Algorithm: Logistic Regression via Gradient Descent
Initialize: w = 0, b = 0 (or small random values)

for epoch = 1 to T:
  // Forward pass
  z = Xw + b // (m,) linear scores
  p̂ = σ(z) = 1/(1+exp(−z)) // (m,) probabilities
  J = (−1/m) Σ [y·log(p̂) + (1−y)·log(1−p̂)] // scalar loss

  // Backward pass
  dw = (1/m) Xᵀ(p̂ − y) // (n,) gradient
  db = (1/m) Σ(p̂ − y) // scalar gradient

  // Update
  w = w − α·dw
  b = b − α·db

return w, b

The Journey: Perceptron → Logistic Regression

1

Perceptron: The Foundation

Linear score z = wᵀx + b, hard threshold, discontinuous update. Works only on linearly separable data.

2

Smooth Activation: Replace step with σ(z)

Derived from the odds ratio. Gives continuous probabilities ∈ (0,1). Differentiable everywhere — gradient descent becomes possible.

3

Probabilistic Model: Bernoulli + MLE

Model outputs P(y=1|x). Training objective derived from maximum likelihood — find weights that make the observed data most probable.

4

Cross-Entropy Loss: Negate log-likelihood

Convex loss surface — no local minima. Combines log(p̂) for positive and log(1−p̂) for negative examples. Heavy penalties for confident wrong predictions.

5

Gradient Descent: Chain rule gives (p̂−y)·x

The gradient simplifies beautifully. σ'(z) cancels with terms in ∂J/∂p̂, giving the clean update rule that echoes the Perceptron.

∂ From a binary threshold to a probabilistic model — the key insight is that smooth approximations unlock calculus, and calculus unlocks optimization.

Logistic Regression remains the bedrock of modern ML: the final layer of neural networks for binary classification is simply this derivation applied at scale.
