1. Ensemble Methods - Beyond Single Trees

🔍 Why Ensembles Dominate

Bias-Variance Trade-off: Single decision trees have low bias (can fit complex patterns) but high variance (sensitive to training data). Ensembles reduce variance while maintaining low bias.

Empirical Success: Random Forests, Gradient Boosting, and XGBoost consistently win Kaggle competitions and power production ML systems.

Random Forests - Bagging + Feature Randomness

Core Idea: Train \(B\) trees on bootstrap samples with random feature subsets, then average predictions.

Algorithm:

  1. Bootstrap sampling: For each tree \(b = 1, ..., B\):
    • Sample \(n\) examples with replacement from training set
    • Creates diversity: each tree sees ~63.2% unique samples
  2. Random feature selection: At each split:
    • Randomly select \(m\) features from total \(d\) features
    • Common: \(m = \sqrt{d}\) for classification, \(m = d/3\) for regression
    • Find best split among these \(m\) features only
  3. Grow trees to full depth: No pruning (reduces bias)
  4. Aggregate predictions:
    • Classification: Majority vote \(\hat{y} = \text{mode}\{\hat{y}_1, ..., \hat{y}_B\}\)
    • Regression: Average \(\hat{y} = \frac{1}{B}\sum_{b=1}^B \hat{y}_b\)

Why It Works - Mathematical Insight:

For regression, if trees are perfectly decorrelated and each has variance \(\sigma^2\):

$$\text{Var}(\bar{Y}) = \frac{\sigma^2}{B}$$

In practice, trees are correlated with correlation \(\rho\):

$$\text{Var}(\bar{Y}) = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$$

As \(B \to \infty\), variance approaches \(\rho\sigma^2\). Feature randomness reduces \(\rho\)!

Complete Random Forest Implementation import numpy as np from collections import Counter from joblib import Parallel, delayed class RandomForestClassifier: def __init__(self, n_estimators=100, max_features='sqrt', max_depth=None, min_samples_split=2, bootstrap=True, n_jobs=-1, random_state=None): self.n_estimators = n_estimators self.max_features = max_features self.max_depth = max_depth self.min_samples_split = min_samples_split self.bootstrap = bootstrap self.n_jobs = n_jobs self.random_state = random_state self.trees = [] def _get_max_features(self, n_features): if self.max_features == 'sqrt': return int(np.sqrt(n_features)) elif self.max_features == 'log2': return int(np.log2(n_features)) elif isinstance(self.max_features, int): return self.max_features else: return n_features def _bootstrap_sample(self, X, y, random_state): """Generate bootstrap sample""" n_samples = X.shape[0] rng = np.random.RandomState(random_state) indices = rng.choice(n_samples, n_samples, replace=True) return X[indices], y[indices], indices def _fit_tree(self, X, y, tree_idx): """Fit a single tree (for parallel execution)""" random_state = None if self.random_state is None else self.random_state + tree_idx # Out-of-Bag (OOB) Error Estimation

Key Insight: Each tree is trained on ~63.2% of data. The remaining ~36.8% (out-of-bag samples) provide a free validation set!

OOB Prediction for sample \(i\):

$$\hat{y}_i^{\text{OOB}} = \text{majority vote of trees where } i \notin \text{bootstrap sample}$$

OOB Error:

$$\text{OOB Error} = \frac{1}{n}\sum_{i=1}^{n} \mathbb{1}(y_i \neq \hat{y}_i^{\text{OOB}})$$

This estimates generalization error without need for separate validation set!

Gradient Boosted Decision Trees (GBDT)

Core Idea: Train trees sequentially, each correcting errors of previous ensemble.

Algorithm (for regression):

Initialize:

$$F_0(x) = \arg\min_\gamma \sum_{i=1}^{n} L(y_i, \gamma)$$

For squared loss: \(F_0(x) = \bar{y}\) (mean)

For \(m = 1\) to \(M\) (number of trees):

  1. Compute pseudo-residuals (negative gradient): $$r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$$ For squared loss: \(r_{im} = y_i - F_{m-1}(x_i)\)
  2. Fit tree \(h_m(x)\) to pseudo-residuals: $$h_m = \arg\min_h \sum_{i=1}^{n} (r_{im} - h(x_i))^2$$
  3. Update ensemble: $$F_m(x) = F_{m-1}(x) + \nu \cdot h_m(x)$$ where \(\nu\) is learning rate (shrinkage)

Final model:

$$F(x) = F_0(x) + \nu\sum_{m=1}^{M} h_m(x)$$

2. Oblique Decision Trees

🔍 Beyond Axis-Aligned Splits

Problem: Standard trees use splits like \(x_j \leq \theta\). To approximate a diagonal boundary requires many axis-aligned splits.

Solution: Use linear combinations: \(\mathbf{w}^T\mathbf{x} \leq \theta\)

Oblique Split:

$$\sum_{j=1}^{d} w_j x_j \leq \theta$$

Finding optimal \(\mathbf{w}\) and \(\theta\):

This is an optimization problem. Common approaches:

  • Linear Discriminant Analysis (LDA): Find linear combination that best separates classes
  • Simulated Annealing: Stochastic optimization
  • Gradient Descent: Optimize impurity w.r.t. weights (requires differentiable impurity)

Trade-off:

  • Pro: More expressive, fewer splits needed
  • Con: Loss of interpretability, slower training, risk of overfitting

Optimizing Tree Traversal class OptimizedTree: """Optimized tree for fast inference""" def __init__(self, sklearn_tree): # Pre-process tree structure for faster lookup self.features = sklearn_tree.tree_.feature self.thresholds = sklearn_tree.tree_.threshold self.left = sklearn_tree.tree_.children_left self.right = sklearn_tree.tree_.children_right self.values = sklearn_tree.tree_.value # Cache leaf predictions self.predictions = np.argmax(self.values.squeeze(), axis=1) def predict_single(self, x): """Optimized prediction for single sample""" node = 0 # Start at root while self.left[node] != -1: # Not a leaf feature = self.features[node] threshold = self.thresholds[node] if x[feature] <= threshold: node = self.left[node] else: node = self.right[node] return self.predictions[node] def predict_batch(self, X): """Vectorized batch prediction""" n_samples = X.shape[0] predictions = np.zeros(n_samples, dtype=np.int32) nodes = np.zeros(n_samples, dtype=np.int32) # All start at root # Track which samples are still traversing active = np.ones(n_samples, dtype=bool) while active.any(): # Get features and thresholds for current nodes features = self.features[nodes[active]] thresholds = self.thresholds[nodes[active]] # Evaluate splits active_X = X[active] comparisons = active_X[np.arange(active_X.shape[0]), features] <= thresholds # Update nodes nodes_active = nodes[active] nodes_active[comparisons] = self.left[nodes_active[comparisons]] nodes_active[~comparisons] = self.right[nodes_active[~comparisons]] nodes[active] = nodes_active # Check which samples reached leaves at_leaf = self.left[nodes] == -1 active &= ~at_leaf return self.predictions[nodes] # Benchmark import time optimized = OptimizedTree(clf) start = time.time() for _ in range(1000): predictions = optimized.predict_batch(X_test) print(f"Optimized: {time.time() - start:.4f}s")

1. Neural Decision Trees

🔬 Merging Trees with Deep Learning

Idea: Make decision trees differentiable so they can be trained with gradient descent and integrated into neural networks.

Soft Decision Trees (Frosst & Hinton, 2017)

Replace hard splits with soft probabilistic splits:

Hard split:

$$\mathbb{1}(\mathbf{w}^T\mathbf{x} \leq \theta)$$

Soft split (sigmoid):

$$\sigma(\mathbf{w}^T\mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T\mathbf{x} + b)}}$$

Path probability to leaf \(\ell\):

$$p(\ell|\mathbf{x}) = \prod_{n \in \text{path}(\ell)} p_n(\mathbf{x})$$

where \(p_n(\mathbf{x})\) is the probability of going left/right at node \(n\).

Final prediction:

$$\hat{y} = \sum_{\ell \in \text{leaves}} p(\ell|\mathbf{x}) \cdot \text{prediction}(\ell)$$

This is fully differentiable! Train with backpropagation.

3. Advanced Splitting Criteria

Information Gain Ratio (C4.5):

$$\text{GainRatio} = \frac{\text{IG}}{\text{SplitInfo}}$$

Distance-based Splitting:

For imbalanced data, maximize distance between class centroids:

$$\max_{\text{split}} ||\mu_{\text{left}}^{(+)} - \mu_{\text{right}}^{(-)}||^2$$

DKM (Distance, Kernel, Mahalanobis):

Use kernel methods to find non-linear decision boundaries while maintaining tree structure.
