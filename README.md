## 🔗 How to Set Up Links

### **Step 1: Create the HTML file**
1. Save the HTML code above as `map.html` in your repository root
2. Commit and push to GitHub

### **Step 2: Enable GitHub Pages**
1. Go to repository **Settings** → **Pages**
2. Set source to **main branch** (or to the folder containing `map.html`)
3. Save - Your map will be available at: `https://[username].github.io/Machine-Learning/map.html`

### **Step 3: Update README.md**
Add this to your main README.md:

```markdown
